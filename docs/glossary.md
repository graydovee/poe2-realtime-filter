# 术语表

界面文案、文档、提示信息和代码注释说到这些概念时，一律用这里的说法。括号里是界面上对应的原文。

## 方案

**方案**是一个完整的过滤器方案：赛季、基础过滤器、对基础规则的修改、自定义规则、跳过物品和音效合在一起，生成一份能装进游戏的过滤器。客户端里一个方案对应游戏里的一个 `.filter` 文件，文件名就是方案名。

| 术语 | 含义 |
| --- | --- |
| 客户端 | PoE2 Realtime Filter 这个桌面程序。 |
| 方案库 | 列出当前服务器全部方案的主界面。 |
| 编辑器 | 编辑一个方案的界面（「编辑」「编辑方案」），从上到下是赛季与行情、基础过滤器、自定义规则三个模块。 |
| 检查器 | 右侧的常驻面板。方案库里显示方案详情和设置，编辑器里显示当前规则的实时效果和方案摘要。 |
| 方案名 | 同时是游戏里的过滤器文件名，同一服务器内不能重名。 |
| 方案描述 | 方案的一段说明，一行文字，最多 200 个字符。显示在方案库的卡片和方案详情里，随分享码和方案包一起分享。 |
| 方案摘要 | 编辑器检查器顶部对当前方案的概括，点一行跳到对应的模块。 |
| 方案设置 | 赛季、严格度、风格和语言这些方案级选项。 |

## 规则

**规则**是方案内的一条过滤规则，决定一批物品掉落时怎样显示。它由两部分组成。

匹配条件，即哪些物品会命中：

- **选择物品**（卡片「物品条件」）：指定物品，或整个分类。
- **价格条件**：按行情价格筛选，填的是价格区间，即下限（含）、上限（不含）和单位。行情给出的是物品价格，所以叫价格条件。
- 两者同时启用时取交集。还可以叠加掉落条件。

特效和音效，即命中之后怎样显示、播放什么声音：

- **特效**：光柱、地图图标、字体（字号、文字颜色、边框颜色、背景颜色）。光柱可以设成**临时**，物品掉落时只短暂显示。地图图标由形状、颜色和尺寸（大 / 中 / 小）三项组成。
- **音效**：内置音效（游戏自带）、基础过滤器音效（基础过滤器自带的文件）或自定义音效。自定义音效是选进方案的音频文件，方案里的每条规则和每处修改都能在音效下拉里直接选它。

规则按列表顺序匹配，首条命中的生效。打开「隐藏物品」的规则把命中的物品隐藏，其余规则让它们显示。

| 术语 | 含义 |
| --- | --- |
| 自定义规则 | 方案的规则列表，叠加在基础过滤器之上。「仅自定义规则」表示方案没有基础过滤器。 |
| 基础规则 | 基础过滤器里的一条规则。打开「显示基础规则」开关后列在规则列表的下面，按分节排列，可以搜索。 |
| 修改 | 方案对一条基础规则做的改动，界面里叫「基础规则修改」。能改它的显示或隐藏、匹配条件、光柱、地图图标、字号、文字/边框/背景颜色和音效；没改的项沿用基础规则。生成时在原位置替换这条规则。修改随方案保存，随分享码和方案包分享。 |
| 基础规则修改开关 | 标题栏的「基础规则修改：开 / 关」按钮，写着「开」时按下，是方案里全部修改的总开关。关闭时全部修改不生效、基础规则只读，每处修改自己的启用状态保留着；打开后各自按启用状态生效。 |
| 失效 | 修改在当前基础过滤器上找不到对应的规则：方案换了别的基础过滤器，或者同名基础过滤器更新后那条规则的条件变了、没了。失效的修改不生效，方案照常生成和安装；换回对应的基础过滤器后恢复。 |
| 批量操作 | 规则面板右上角的菜单：在规则之间复制、粘贴条件和特效；基础规则修改开关打开时，还能复制、粘贴整个方案的修改，或者用「还原基础规则」去掉全部修改。单条规则在它的编辑区里还原。 |
| 单件价格 | 一件物品的行情价格，价格条件比较的就是它。 |
| 隐藏规则 | 打开了「隐藏物品」的规则。它写的效果照样生效，命中的物品默认不显示，按住 Alt 才显示。 |
| 单位 | 价格条件的计价通货：崇高石、混沌石、剥离石或神圣石。规则列表里简写成 E、C、剥离石、D。 |
| 价格档 | 新方案自带的四条价格条件规则：崇高石、混沌石、剥离石、神圣石价格档。每档匹配「不低于一枚本档通货，且低于一枚下一档通货」的物品，最高档不封顶，物品默认是通货、玩法、符文、精髓四个分类里的物品。它们是普通规则，数值、单位和物品都能改。 |
| 特效预设 | 从基础过滤器里提取的一套完整特效，连同音效，可以一次套用到规则上。 |
| 固定特效 | 规则自己保存的特效值。手动改过外观或音效的规则使用固定特效。 |
| 跟随基础特效 | 规则只记一个来源物品，使用那件物品在当前基础过滤器里的特效。界面里叫「特效来源」。切换基础过滤器后自动跟着变。 |
| 基础特效 | 基础过滤器里某件物品原有的特效，是特效预设和跟随基础特效的来源。 |
| 掉落条件 | 按堆叠数量、稀有度、物品等级、孔数和未鉴定阶级筛选，属于匹配条件。 |

## 方案的其他组成

| 术语 | 含义 |
| --- | --- |
| 赛季 | 方案使用的游戏赛季。行情和生成版本随赛季变化。 |
| 行情 | 物品的单件价格和通货汇率，按服务器和赛季缓存。价格条件用它把价格换算成崇高石比较。 |
| 行情时间 | 行情快照的抓取时间。已安装的过滤器记着自己生成时所用行情的时间，方案卡片和方案详情显示的就是它；未安装的方案没有行情时间。 |
| 服务器 | 国际服或腾讯服（「国际服 POE2」「腾讯服 POE2」）。两服各有自己的方案、赛季和行情，共用游戏过滤器目录。 |
| 基础过滤器 | 方案在其上叠加自定义规则的那份现成过滤器。来源有游戏订阅、下载来源、本地文件，以及方案包导入的副本。 |
| 跳过物品 | 方案里的一份名单，其中的物品不交给自定义规则处理，沿用基础过滤器原有的显示。 |
| 物品 | 物品目录里的一件东西，是选择物品的最小单位。 |
| 物品目录 | 客户端认识的所有物品和它们的分类，记在 `data/item-catalog.json`。 |
| 分类树 | 物品选择器左侧的分类，顶层依次是通货、传奇、玩法、终局、符文、精髓、技能、装备、其他，记在 `data/item-categories.json`。 |
| 基底 | 游戏术语，物品的基础类型（`BaseType`）。 |

## 生成与安装

| 术语 | 含义 |
| --- | --- |
| 过滤器 | 方案生成出来的 `.filter` 文件，连同它需要的音效文件。装进游戏后，在游戏设置里按方案名选用。 |
| 游戏过滤器目录 | 游戏读取过滤器的目录，在方案库检查器的「过滤器目录」里设置。 |
| 生成预览 | 在编辑器里生成过滤器并查看结果（「生成预览」「预览」）。 |
| 安全检查 | 生成前对规则和基础过滤器做的检查，例如会隐藏高价值物品，或用了游戏已经改名的物品类别。不通过时不安装。 |
| 安装 | 把生成的过滤器写进游戏过滤器目录（「安装到游戏」）。 |
| 卸载 | 从游戏过滤器目录删掉过滤器，保留方案（「卸载过滤器」）。 |
| 重新生成 | 按当前行情和方案再生成一次并安装（「重新生成」）。 |
| 自动刷新 | 已安装的方案跟随行情和下载来源的更新，由托盘定时重新生成（「自动刷新」）。 |
| 托盘 | 关闭窗口后留在系统托盘里的客户端，负责后台刷新。 |

## 分享与备份

| 术语 | 含义 |
| --- | --- |
| 分享码 | 一段以 `POE2F` 开头的文本，带规则、对基础规则的修改、方案设置、名称和描述。每次导入都创建新方案。 |
| 目录版本 | 物品目录的版本，写在分享码里。物品的分享地址只在同一个版本内有效，所以版本不一致的分享码不导入。只在旧的地址无法继续沿用时加一。 |
| 方案包 | 一个 ZIP，带一个或多个完整的方案，连同它们用到的基础过滤器和自定义音效。按方案 ID 识别，再次导入时更新。 |
| 下载 ZIP | 导出生成好的过滤器和音效，可以直接放进游戏使用。 |
| 基础过滤器表 | `data\base-filters.json`，登记进出过方案包的基础过滤器。 |
