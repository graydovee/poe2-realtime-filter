# 设计系统

Windows 客户端使用深色工作台：铺满窗口的应用框架、右侧常驻检查器、三个自上而下堆叠的模块。炭灰底区分应用、面板与卡片，暖白用于文字，暖金只标记主操作、选中态和焦点。

设计依据是 [ui-ux-pro-max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) 对「开发工具 / 桌面工具」的推理结论：`Dark Mode + Minimalism & Swiss Style`、高密度布局、克制的微动效、命令面板与键盘快捷键。

## Token

定义在 `app/globals.css` 的 `:root`（`--color-*`，RGB 三元组，供 Tailwind 的 `rgb(var(--color-x) / <alpha-value>)` 使用），并通过 `tailwind.config.ts` 映射成 `bg-surface`、`text-ink`、`border-line` 这类工具类。

| 语义 | Token | 值 | 用在哪 |
|---|---|---|---|
| 应用底色 | `--color-bg` | 11 13 16 | 窗口底、代码区 |
| 面板 | `--color-surface` | 20 23 28 | 模块、顶栏、检查器 |
| 面板 2 | `--color-surface-2` | 26 30 37 | 卡片、输入框、弹层 |
| 面板 3 | `--color-surface-3` | 35 40 48 | 悬停、选中底色、提示 |
| 描边 | `--color-line` | 48 55 64 | 面板、卡片、分隔线（装饰） |
| 描边-强 | `--color-line-strong` | 86 97 112 | 输入框、按钮、复选框的边框 |
| 文字 | `--color-ink` | 244 241 234 | 正文、标题 |
| 次要文字 | `--color-ink-muted` | 161 169 178 | 说明、标签、次级信息 |
| 提示文字 | `--color-ink-faint` | 135 145 156 | 占位符、字段提示、快捷键提示 |
| 金色 | `--color-gold` | 215 170 83 | 主按钮、选中态 |
| 金色-亮 / 按下 | `--color-gold-bright` / `--color-gold-press` | 239 199 117 / 190 142 57 | 悬停、强调文字 / 按下 |
| 金色上的文字 | `--color-on-gold` | 23 19 13 | 主按钮文字 |
| 血焰 | `--color-ember` | 255 158 148 | 错误、危险、隐藏规则 |
| 暖绿 | `--color-sage` | 161 210 149 | 成功、已安装、启用 |
| 稀有度（普通/魔法/稀有/传奇） | `--color-rarity-*` | 200 200 200 / 136 136 255 / 255 255 119 / 175 96 37 | 物品选择器和掉落预览 |

稀有度使用游戏官方配色，让物品选择器和掉落预览与游戏一致。

对比度（已按 WCAG 公式核算）：正文、次要文字、提示文字、金色、血焰、暖绿在四档底色上都不低于 4.5:1。控件边框（`line-strong`）相对输入框底色约 2.7:1、相对面板约 2.9:1，低于非文字对比度 3:1 的建议值，靠边框与底色差一起标识控件边界；面板描边（`line`）是装饰性的。

## 排版

- 界面 `Inter`（OFL）+ 中文系统栈：`PingFang SC` / `Microsoft YaHei UI` / `Noto Sans SC`。
- 等宽 `JetBrains Mono`（OFL）：价格、汇率、序号、过滤器代码。
- 展示体 `Cinzel`（OFL）：只用于品牌字标。
- 三种字体由 `@fontsource/*` 提供，通过 `app/layout.tsx` 打包进客户端（CSP 只允许同源资源）。
- 字号刻度：`xs` 12px、`sm` 13px、`base` 14px，正文行高 1.6；界面文字不小于 12px。
- 界面文案全部中文；英文只保留品牌字标、过滤器语法和专有名词。
- 按钮和菜单项的文字不带省略号；进行中的状态文字以省略号结尾（如「保存中…」「正在读取本地方案…」）。

## 形状、层级与动效

- 圆角：控件 4–6px，卡片 8–10px，对话框 14px。
- 层级：面板 = 1px `line` 描边 + 顶部 1px 内高光；卡片比面板深/浅一档并用描边分隔；弹层（对话框、菜单、提示）用 `surface-2` + 大投影，永远浮在界面之上。
- 金色只用于：主按钮（金色渐变 + 内高光）、选中态、焦点环、序号与标题前的小菱形装饰。其余按钮是描边、幽灵、危险三种。
- 应用底色带一抹极淡的金色光晕和一层细噪点（`.app-frame`），只露出在面板之间的缝隙里。
- 动效 120–180ms `ease-out`，只动 transform / opacity / 颜色；`prefers-reduced-motion` 下全部关闭。
- 键盘焦点统一为 2px 亮金描边。设置项使用切换开关，禁用时轨道改为虚线描边，状态说明保持正常对比度。
- 图标统一使用 `lucide-react`，装饰性图标加 `aria-hidden`，只有图标的按钮必须有可读标签。

## 布局

应用铺满窗口（`h-dvh`）：

```
┌──────────────────────────────────────────────────────────────┐
│ 顶栏：品牌 · 视图上下文 · 服务器 · 更新 · 命令面板 · 检查器开关 │
├──────────────────────────────────────────┬───────────────────┤
│ 主区（唯一的滚动容器）                    │ 检查器（可拖宽）   │
├──────────────────────────────────────────┴───────────────────┤
│ 状态栏：行情状态 · 快捷键提示                                 │
└──────────────────────────────────────────────────────────────┘
```

- **顶栏**：方案库里可切换服务器；编辑中服务器只读显示。方案名是一个按钮，前面带铅笔图标，点开修改名称和描述；方案名右侧是未保存状态。
- **检查器**：宽于 1180px 时停靠在右侧（默认 320px，可拖到 280–440px，展开状态记在本地）；更窄时默认收起，用顶栏按钮或 `Ctrl+\` 从侧边滑出。
- **方案库**：工具栏左侧是「新建方案」和两个导入入口（方案包、分享码），搜索框旁是「导出方案包」。方案卡片从上到下是名称和状态徽标、描述（有才显示，单行截断）、摘要；已安装的方案在摘要同一行的右端显示行情时间，放不下时折到下一行。方案详情的「分享」一节以「导出方案包」为唯一的大按钮，「分享码」和「下载 ZIP」是它下面并排的两个小按钮。
- **编辑器**：三个模块自上而下——赛季与行情、基础过滤器（含跳过物品，默认折叠，需要处理时自动展开）、自定义规则。规则模块在内容区宽于 768px 时排成「规则列表 | 规则编辑器」两栏，更窄时规则列表变成一行可横向滚动的标签。
- **容器查询**：规则模块和规则编辑器的断点按各自内容区宽度计算（`@container` / `@3xl:`），与窗口宽度无关，所以拖动检查器时会自然重排。查询条件相对祖先容器求值，列模板要写在容器的子元素上。
- 最小窗口 720×600 下所有界面可用。

## 反馈与操作

- 成功的操作用 toast（`sonner`）反馈；错误就近显示在对话框内或列表顶部，不打断操作。
- 对话框统一用 Radix Dialog（`ConfirmDialog`），菜单用 DropdownMenu，提示用 Tooltip，下拉选择用 Select。
- 删除规则后 toast 里提供「撤销」。
- **耗时操作显示进度，并且能取消。** 下载基础过滤器时显示当前阶段（检查新版本、已下载大小和百分比、解压）和已等待的秒数；已下载的版本先列出来，检查期间就能选用。
- 拖拽排序（`@dnd-kit`）始终配有等价的按钮操作（上移 / 下移）和键盘操作（手柄上按空格拿起、上下键移动）。
- 每个视图外层有错误边界，单个模块渲染出错不会拖垮整个窗口。
- **界面只显示名字和来源。** 基础过滤器显示名字和来源（本地文件 / 订阅类型 / 下载来源和版本），完整路径放在悬停提示里；「过滤器目录」设置框显示并编辑路径。
- **列表项必须能收缩。** 网格或弹性布局里的条目要加 `min-w-0`，不换行的文字用 `w-full` 加 `truncate`，这样一行长文字不会把整行撑到比容器还宽。

自定义规则编辑器的交互约定：

- 每条规则由匹配条件、特效和隐藏开关组成。可以按物品、价格或两项同时筛选；物品条件和价格条件至少保留一个启用。
- 选择物品在对话框里完成（`item-picker`），选好的物品以标签形式显示在条件卡片里，可以逐个移除。
- 「完整特效预设」一次应用光柱、地图图标、字体和音效；预设画廊是非模态弹层，点选即应用，右侧检查器的实时预览跟着更新。展开「高级外观设置」可以调整单项特效。
- 「高级外观设置」里的颜色都用色块选。光柱和地图图标的颜色点开固定调色盘：游戏给的 11 种颜色每格一种，下面标着名字，光柱的调色盘多一格「沿用基础」。文字、边框、背景颜色在文本框旁点开取色器：色面选饱和度和明度，滑块调色相和透明度，下面是预设颜色，改动即时反映到实时预览。地图图标分成形状、颜色、尺寸（大 / 中 / 小）三项，选了形状才有图标；新选形状时颜色默认跟光柱一致，尺寸默认「中」。光柱带一个「临时」开关，打开后只在物品掉落时短暂显示。
- 音效下拉分「自定义音效」和「内置音效」两组：自定义音效是方案里各条规则已经选过的音频文件，每条规则都能直接选，组里最后一项是「选择文件」。下拉旁常驻一个「选择文件」按钮，选进来的文件立刻成为当前规则的自定义音效；它和别的规则在用的音效同名但内容不同时，自动另起一个名字。
- 价格区间的两个端点都是普通的「数值 + 单位」输入，单位下拉来自 `PRICE_UNITS`（崇高石、混沌石、剥离石、神圣石）。四个默认价格档和其他规则用同一套控件：默认沿用的样式表现为预设卡上的高亮加一行说明，换一个预设或改任意一项就变成规则自己的特效。
- 价格下限不低于上限时，价格卡下方显示一行红色提示。
- 当前规则在游戏里的掉落效果（光柱、标签、地图图标）始终显示在检查器顶部，可以试听音效。地图图标按游戏里的图标描摹轮廓，12 种形状各不相同。
- 方案摘要在检查器里，点某一行会跳到对应的模块。

物品选择器（`item-picker`）的交互约定：

- 左侧是分类树（三态勾选），右侧是当前分类的子类卡片或物品列表（虚拟滚动）。
- 分类树：顶层依次是通货、传奇、玩法、终局、符文、精髓、技能、装备、其他。「装备」只收录会以普通、魔法或稀有掉落的基底，防具按属性需求拆开（例如「头盔(力敏智)」）；「传奇」是独立的顶层分类，条目的名字是传奇的名字，第二行是「传奇 · 基底名」，按基底名也能搜到。
- 分类的名字和顺序取自 `data/item-categories.json`，名字按完整路径取（同一个名字可以在不同父分类下重复出现，例如各玩法下的「碎片」），最深四层（装备 › 头盔 › 头盔(力)）。
- 分类树每一行和子类卡片都带图标。分类自己的图片记在 `data/item-categories.json` 的 `icon` 里，是图床上的地址，和物品图标一样第一次用到时取回并缓存在本地；没有单独图片的分类用分类下第一件带图标的物品的图标，子分类按显示顺序找，都没有时用和物品一样的占位图标。分类树里是 16px 的图，和勾选框同宽；子类卡片是和物品行相同的 40px 图标位；「全部分类」用 `Layers`。
- 顶部有搜索、仅看已选、全选本类 / 取消所选 / 全选可堆叠物品。未切割宝石的每个等级是一件独立物品，直接勾选对应的等级；子类卡片要放得下「头盔(力敏智)」这样的分类名，列宽不小于 `15rem`，名字最多两行。
- 物品列表是两列虚拟列表。每个格子是一条独立的虚拟行，行容器不接收鼠标事件，只有自己的那一格可以点；列宽写死等分，不随内容变化。
- 全选一个分类保存的是逐件物品，生成过滤器时由生成器判断要不要合并成一条 `Class` 条件（规则见 `docs/filter-generation.md`）。换界石按阶数各是一件物品，「终局 › 换界石」从 16 阶排到 1 阶。远征日志、任务物品是没有逐件物品的整类条目，在各自的分类下就是一件普通物品（按分类名显示），选中它就是整类匹配。
- 规则物品和跳过物品共用同一个对话框，改动即时生效，关闭即完成。
